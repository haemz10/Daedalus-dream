# 다이달로스의 꿈 · Daedalus Dream

> 들어가는 길은 있어도, 나오는 길은 없는 꿈.
> *A dream with a way in, and no way out.*

어린 소녀는 매일 밤 같은 꿈을 꿉니다. 어둠 속에서 발견한 샛노란 정글짐 미로. 입구는 보이지만 출구는 보이지 않습니다.
입구에는 키가 아주 큰 키다리 아저씨가 서서 미소 지으며 묻습니다. *"들어와서 같이 놀지 않을래?"*

- **미로에 들어간다** → 게임 시작
- **꿈에서 깬다** → 방에서 깨어났다가 다시 잠들고, 같은 꿈으로 돌아옵니다. 몇 번이든 거절할 수 있지만, 꿈은 돌아올 때마다 조금씩 이상해집니다. 결국 미로에 들어가야 합니다.

휴대폰 브라우저에서 바로 실행되는 **모바일 웹게임(PWA)** 입니다. 홈 화면에 추가하면 앱처럼 전체 화면으로 실행되고, 한 번 연 뒤에는 오프라인에서도 플레이할 수 있습니다. 그림과 음악은 모두 코드로 그리고 합성해서 이미지·음원 파일이 없습니다.

## 플레이 방법

| 조작 | 터치 | 키보드 |
| --- | --- | --- |
| 봉을 따라 달리기 | 스와이프 한 번 | 방향키 / WASD |
| 본 적 있는 곳으로 걸어가기 | 그 지점을 탭 | — |
| 돌림 이음새 돌리기 | 이음새를 탭 | Space / Enter |
| 미로 넓게 보기 | 돋보기 버튼 | Z |
| 다시 시작 | ↻ 두 번 탭 | R 두 번 |
| 일시정지 | Ⅱ 버튼 | Esc / P |

시작 화면 왼쪽 위(와 일시정지 메뉴)의 스피커 버튼으로 소리를 켜고 끕니다. 설정에서 화면 방향 버튼, 진동, 움직임 줄이기, 음악·효과음 크기를 바꿀 수 있습니다.

### 소녀가 움직이는 방식
스와이프 한 번이면 소녀는 **막힐 때까지 그 방향으로 쭉 달립니다.**
- 길이 한 방향으로만 꺾여 있으면 **알아서 모퉁이를 돌아** 계속 달립니다.
- **갈림길에서 앞이 막혀 있으면 멈춥니다.** 어느 쪽으로 갈지 플레이어가 골라야 하는 곳이기 때문입니다.
- 달리는 도중에 미리 스와이프해 두면, **그 방향으로 꺾을 수 있는 첫 지점에서 자동으로 꺾습니다.**
- 반대 방향으로 스와이프하면 즉시 되돌아갑니다.

### 미로의 규칙
- 어둠 속 소녀의 등불 주변만 보입니다. 한 번 지나간 곳은 희미하게 기억됩니다.
- **꿈 조각 ✦** 을 모두 모으면 숨어 있던 **출구**가 나타납니다.
- 봉 위에는 **별가루 ✧** 가 깔려 있습니다. 멈추지 않고 연달아 먹으면 **콤보**가 쌓이고(10콤보마다 점수 배율 상승, 최대 ×5), **30콤보**가 되면 **피버**: 6초 동안 더 빨리 달리고, 등불이 넓어지고, 점수가 2배가 됩니다. 1.6초 동안 새 별가루를 못 먹으면 콤보가 끊깁니다.
- 점수: 별가루, 꿈 조각, 황금 구슬, 클리어 보너스, 남은 시간 보너스, 무피해 보너스, 별가루 전부 수집 보너스. 스테이지별 최고 점수가 저장됩니다.
- 스테이지마다 **황금 구슬**이 하나씩 숨어 있습니다. 30개를 모두 모으면 진엔딩을 볼 수 있습니다.
- 별 3개: 탈출 · 황금 구슬 · 하트를 하나도 잃지 않기.
- 하트 3개. 모두 잃으면 키다리 아저씨에게 잡힙니다.

### 미로의 장치 (스테이지가 진행되면서 하나씩 등장)
| 장치 | 설명 |
| --- | --- |
| 종 🔔 | 밟을 때마다 분홍 봉과 파란 봉이 번갈아 나타납니다 |
| 웃는 풍선 | 미로 위를 떠다닙니다. 닿으면 하트를 잃습니다 |
| 돌림 이음새 | 탭하면 90°씩 돌아가며 연결이 바뀝니다 |
| 기다란 손 | 그림자가 드리운 뒤 위에서 내려와 잡습니다. 그림자를 보면 피하세요 |
| 미끄럼 봉 | 화살표 방향으로만 지나갈 수 있습니다 |
| 열쇠와 자물쇠 | 열쇠를 주우면 잠긴 봉을 열 수 있습니다 |
| 녹슨 봉 | 한 번 건너면 부서집니다. 길이 완전히 막히면 게임이 알려 줍니다 |
| 소용돌이 | 들어가면 짝꿍 소용돌이로 나옵니다 |

## 구성
- **스토리 모드**: 3장 × 10스테이지 = 30스테이지, 장 사이의 막간 이야기, 엔딩 2종(일반 / 황금 구슬 30개 진엔딩).
- **끝없는 정글짐**: 1장(1-10)을 깨면 열립니다. 층마다 새로 생성되는 미로를 얼마나 깊이 내려가고 몇 점을 낼 수 있는지 도전합니다. 5층마다 하트 +1.
- **언어**: English(기본) · 한국어 · 日本語 · Français · Español · 中文. 처음 화면 오른쪽 위 버튼이나 설정에서 바꿀 수 있습니다.

## 실행하기

빌드 과정이 없는 순수 HTML/JavaScript입니다.

```bash
python3 -m http.server 8765        # 또는 npm start
# 브라우저에서 http://localhost:8765 열기
```

### GitHub Pages로 배포 (휴대폰에서 링크로 플레이)
> 무료 GitHub 계정에서는 **공개(Public) 저장소만** Pages를 쓸 수 있습니다. 비공개 저장소라면 먼저
> **Settings → General → 맨 아래 Danger Zone → Change repository visibility → Make public** 으로 공개로 바꾸거나 GitHub Pro로 업그레이드해야 합니다.

1. GitHub 저장소 → **Settings → Pages**
2. **Build and deployment → Source: Deploy from a branch**, Branch: `main` / `/ (root)` → Save
3. 잠시 후 `https://<사용자명>.github.io/Daedalus-dream/` 에서 실행됩니다.
4. 휴대폰에서 열고 **홈 화면에 추가**(iOS: 공유 → 홈 화면에 추가 / Android: 메뉴 → 앱 설치)하면 앱처럼 실행됩니다.

### 한 파일 버전
```bash
node tools/build.cjs   # dist/daedalus-dream.html 하나로 묶인 버전 생성
```

## 검증과 테스트

```bash
node tools/verify.cjs      # 30개 스테이지를 퍼즐 풀이기로 전부 풀어 보고(황금 구슬 포함), 6개 언어 텍스트 누락,
                           # 끝없는 정글짐 400개 층의 풀이 가능 여부와 생성 속도를 검사
node tests/smoke.cjs       # 아이폰 화면으로 프롤로그 → 3번 거절 → 입장 → 1-1 자동 클리어
node tests/full.cjs        # 30스테이지 + 막간 + 진엔딩 + 끝없는 정글짐 자동 플레이
node tests/interact.cjs    # 탭 이동, 이음새 회전, 키보드, 방향 버튼, 일시정지, 재시작, 잡힘, 막힘 경고, 오프라인
node tests/mobile.cjs      # 실제 터치 스와이프, 뒤로 가기 제스처, 화면 쓸림, 버튼 겹침, 소리 버튼, 콤보·피버 (안드로이드/iOS 크기 5종)
node tests/views.cjs       # 여러 기기(가로/세로, 태블릿, PC)와 언어별 화면 배치
```
테스트는 Playwright(Chromium)를 사용합니다: `npm i -D playwright && npx playwright install chromium`.

## 파일 구조
```
index.html, style.css      화면 구조와 스타일
manifest.webmanifest, sw.js, icons/   PWA(설치·오프라인)
src/
  util.js        공용 도구 (난수, 저장소 등)
  i18n.js        6개 언어 텍스트
  level.js       미로 규칙 (ASCII 지도 해석, 이동·장치 판정)
  solver.js      BFS 퍼즐 풀이기 (검증, 목표 시간, 막힘 감지)
  generator.js   끝없는 정글짐 미로 생성기
  levels.js      스토리 30스테이지 지도
  save.js        진행 상황 저장 (이 기기 브라우저에만)
  audio.js       WebAudio 오르골 음악과 효과음
  render.js      소녀, 키다리 아저씨, 아이템 그리기
  scenes.js      컷신 (꿈, 침실, 막간, 엔딩)
  game.js        미로 안의 게임플레이, 안개, 카메라
  ui.js          화면, 대화, 메뉴, HUD
  input.js       터치·키보드 입력
  main.js        전체 흐름 연출
tools/  verify.cjs · curate.cjs(스테이지 초안 생성) · build.cjs · icons.cjs
tests/  Playwright 브라우저 테스트
```
